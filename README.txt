RESTAR WEB — نسخه آماده انتشار فرانت‌اند

فایل‌های سایت
- index.html: صفحه اصلی فارسی و واکنش‌گرا
- style.css: طراحی، انیمیشن‌ها و حالت موبایل
- script.js: منوی موبایل، انیمیشن ورود و آماده‌سازی درخواست
- favicon.svg: آیکون مرورگر

انتشار رایگان روی GitHub Pages
1) وارد مخزن GitHub خودت شو.
2) Add file > Upload files را بزن.
3) همه فایل‌های همین پوشه را انتخاب و بارگذاری کن؛ خود پوشه را داخل مخزن نگذار.
4) روی Commit changes بزن.
5) در Settings > Pages، گزینه Deploy from a branch را انتخاب کن.
6) Branch را روی main و پوشه را روی /(root) بگذار و Save را بزن.
7) پس از آماده‌شدن انتشار، آدرس سایت در همان صفحه نمایش داده می‌شود.

محدودیت‌های مهم قبل از استفاده تجاری
- این نسخه فرانت‌اند است؛ فرم درخواست را فقط آماده و در صورت پشتیبانی مرورگر کپی می‌کند. اطلاعات به سرور ارسال یا در دیتابیس ذخیره نمی‌شود.
- برای دریافت واقعی سفارش‌ها باید راه ارتباطی واقعی (مثلاً ایمیل یا تلگرام) و یک سرویس فرم/بک‌اند متصل شود. هیچ راه ارتباطی ساختگی در سایت قرار داده نشده است.
- ورود کاربران، پنل مدیریت، پرداخت آنلاین و دیتابیس در این نسخه پیاده‌سازی نشده‌اند.
- پروژه‌های FORME و NØVA کانسپت نمایشی هستند و به‌عنوان نمونه‌کار واقعی مشتری معرفی نشده‌اند.
- فونت‌های Google Fonts در صورت دسترسی به اینترنت بارگیری می‌شوند؛ در غیر این صورت فونت جایگزین استفاده می‌شود.
- پیش از انتشار عمومی، آدرس برند، راه تماس واقعی و شرایط خدمات را اضافه کن.
